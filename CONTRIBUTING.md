# Contributing

If you want to contribute code you can get started by looking at the open issues.
You can also help by filing issues, participating in discussions and doing code review.

## Building prerequisites

* Visual Studio 2026 (Community Edition or higher) is required for building this repository.
* The version of the [.NET Core SDK](https://dotnet.microsoft.com/en-us/download/dotnet) as specified in the global.json file at the root of this repo.
